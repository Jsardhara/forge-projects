# Monetization Plan

## Freemium
- Unlimited read‑only access to public prompts
- Rate limit: 10 requests/minute per IP
- No API key required

## Pro ($9/mo)
- API key for unlimited reads
- Ability to submit prompts
- Rate limit: 200 req/minute
- Dashboard with analytics (views per prompt)

## Enterprise ($49/mo)
- Private workspace for internal prompt libraries
- SSO / OAuth integration
- Webhook callbacks on new prompt submissions

## Break‑even
- Hosting on Fly.io ≈ $5/month
- 5 Pro subscribers cover costs, profit starts at 6+.

## Go‑to‑market
- Launch on Product Hunt with a GIF demo
- Share on r/PromptEngineering, r/AItools
- Offer a 14‑day free trial for Pro tier.
